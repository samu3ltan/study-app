# Study App

Photo-to-flashcard spaced-repetition app for medical and science learners.
Native iPhone, iPad and Mac apps (Swift/SwiftUI), a shared TypeScript server, and
Windows/Android later.

| Folder | What lives there |
| --- | --- |
| `apple/` | One multiplatform Xcode project: iPhone, iPad, Mac |
| `server/` | TypeScript service: AI card pipeline, Anki import/export, sync API |
| `eval/` | Accuracy benchmark: real pages + expected cards, scoring scripts |
| `docs/` | Decisions, setup checklist, subject design notes |

Start with `CLAUDE.md` (how this project is run) and `docs/decisions.md`.
